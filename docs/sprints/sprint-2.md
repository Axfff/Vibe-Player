# Sprint 2 — 自定义多歌单

更新日期：2026-10-25（Asia/Shanghai）。状态：**需求规划；功能未实现、未验收。**

## Sprint Goal

让用户按学习、通勤、跑步等用途保存多个命名的本地歌单，并能重新打开和播放这些集合。

## 风险与待决定事项

1. **曲目关联**：不要只用歌曲标题识别歌曲；先检查当前 MediaStore 与保存恢复逻辑，再选择能支持本轮范围的曲目引用方式。
2. **范围控制**：首轮固定添加顺序；AI 生成、手动排序、导入导出和云同步留待后续讨论。
3. **基线复现**：Sprint 1 有协作者构建日志；仍需为本轮确切提交记录环境、运行结果和回归检查。
4. **验收可执行性**：使用固定本地测试音频，并独立验证移除歌单成员不会影响其他歌单或原文件。

实现位置可参考基线的 `GoPreferences.kt`、`MusicViewModel.kt`、`MainActivity.kt` 及播放代码；这些是起点，不预先要求引入数据库或改写整个播放器。
